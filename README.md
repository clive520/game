# 🎮 NEXUS ARCADE (星際遊戲矩陣平台)

一個專為 **GitHub Pages** 打造的極速、現代化 HTML5 純靜態網頁遊戲平台。

---

## 🌟 平台特色
- **100% 靜態運行**：無任何後端或外部重量套件依賴，秒開載入，原生相容 GitHub Pages。
- **資料驅動多遊戲架構**：透過 `js/games-data.js` 管理遊戲陣容，支援即時關鍵字搜尋、分類過濾與動態卡片渲染。
- **未來科幻視覺風格**：深色電競霓虹美學、自適應響應式佈局 (RWD)。

---

## 🛡️ 首發旗艦遊戲：《星際守望者：迷宮防線》 (Cyber Defense)
- **開放式迷宮建造 (Mazing)**：自訂防禦塔路障引導機械軍團，動態延長敵人行軍路徑。
- **A\* 即時尋路系統**：即時重新計算全場敵人路徑，具備防堵死（Anti-blocking）合法放置檢查。
- **可操控星際指揮官 (The Commander)**：全鍵盤 (WASD) 與滑鼠雙操作，自帶自動機砲與 [Q] EMP 震撼脈衝、[E] 軌道精準轟炸主動技能。
- **4 種高科技防禦塔**：
  1. ⚡ **光子脈衝塔**：高頻射速單體打擊
  2. 🎯 **重力磁軌砲**：極限貫穿一整線的高能射線
  3. 🌀 **電磁緩速塔**：大範圍減速控場
  4. 🚀 **巡弋導彈塔**：大範圍高爆濺射傷害
- **純原生 Web Audio API 音效**：免載入外部音頻，即時程序化合成雷射、爆炸、EMP 與建造音效。

---

## 🚀 本地執行方式
本專案為純靜態網站，無需安裝 npm 或任何構建步驟：
1. 直接使用瀏覽器開啟專案根目錄的 `index.html`。
2. 或在專案目錄下啟動任意本地靜態伺服器（例如 `python -m http.server 8000` 或 VS Code Live Server）。

---

## 📦 目錄架構
```text
Game/
├── index.html                  # 遊戲大廳首頁
├── css/
│   └── portal.css              # 大廳科技風樣式
├── js/
│   ├── games-data.js           # 遊戲清單數據庫
│   └── portal.js               # 搜尋、分類與動態渲染
└── games/
    └── cyber-defense/          # 首款塔防遊戲
        ├── index.html          # 遊戲入口
        ├── css/
        │   └── game.css        # 戰情 HUD 與 Canvas 樣式
        └── js/
            ├── audio.js        # Web Audio API 合成音效引擎
            ├── pathfinding.js  # A* 尋路與防堵死驗證
            ├── entities.js     # 指揮官、塔、敵人、子彈、粒子
            └── game.js         # Canvas 主循環與戰鬥控制器
```
