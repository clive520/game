# 🎮 NEXUS ARCADE (星際遊戲矩陣平台)

一個專為 **GitHub Pages** 打造的極速、現代化 HTML5 純靜態網頁遊戲平台。

* 🌐 **線上遊玩大廳**：[https://clive520.github.io/game/](https://clive520.github.io/game/)
* 🛡️ **《星際守望者：迷宮防線》直達**：[https://clive520.github.io/game/games/cyber-defense/](https://clive520.github.io/game/games/cyber-defense/)

---

## 🌟 平台特色
- **100% 純靜態運行**：無後端與重量依賴，秒開載入，原生相容 GitHub Pages。
- **資料驅動多遊戲架構**：透過 `js/games-data.js` 管理遊戲陣容，支援即時關鍵字搜尋、分類過濾與動態卡片渲染。
- **未來科幻視覺風格**：深色電競霓虹美學、自適應響應式佈局 (RWD)。
- **內建完整操作指引**：大廳與各遊戲內部均附帶「📖 遊玩指南」說明彈窗。

## 🛡️ 首發旗艦遊戲：《星際守望者：迷宮防線》遊玩說明

一款結合「開放式迷宮建造（Mazing）」與「機甲指揮官即時協同」的未來科幻塔防。

### 1. 🎯 作戰目標
- 保護右側藍色能量核心（❤️ 基地生命 20 點），阻止機械敵軍從左側紅色傳送門入侵。
- 堅守並全數殲滅共 **15 波次** 的敵軍即可奪得戰役勝利！

### 2. 🧱 開放式迷宮建造 (Mazing Protocol)
- **造塔阻路**：點擊下方塔牌或按熱鍵 `[1]` ~ `[4]`，滑鼠左鍵點擊地面建造防禦塔。防禦塔會成為障礙物，敵人會依據 **A\* 尋路演算法** 自動重新規劃繞行路線，藉此延長敵軍受火力打擊時間。
- **防堵死警報**：嚴禁將通往核心的路徑完全封死！若擺放會造成敵軍無路可走，系統會亮起紅框警示並拒絕建造。

### 3. 🤖 機甲指揮官操作 (Commander Controls)
| 動作 / 技能 | 熱鍵 / 操作 | 說明 |
| :--- | :--- | :--- |
| **機甲移動** | `W` `A` `S` `D` 或 **滑鼠右鍵** | 操控機甲在戰線上穿梭協防、靈活補位。 |
| **自動等離子砲** | 自動索敵攻擊 | 機甲射程內有敵人時自動高頻開火射擊。 |
| **EMP 震撼脈衝** | 按鍵 `Q` | （冷卻 10s）釋放全場電磁脈衝，造成範圍傷害並使機械敵軍完全癱瘓 3.5 秒。 |
| **軌道精準轟炸** | 按鍵 `E` | （冷卻 18s）對滑鼠游標所在座標呼叫軌道重砲，造成半徑 100 範圍 220 毀滅打擊。 |

### 4. ⚡ 4 種高科技防禦塔庫
1. ⚡ **光子脈衝塔 `[1]` (50 💎)**：造價低廉、射速極快，適合快速構築迷宮長廊通道。
2. 🎯 **重力磁軌砲 `[2]` (120 💎)**：超遠射程，發射高能粒子束瞬間貫穿直線上的所有敵軍！
3. 🌀 **電磁緩速塔 `[3]` (80 💎)**：持續釋放電磁環，降低 50% 移動速度，將敵軍牽制在火力網中。
4. 🚀 **巡弋導彈塔 `[4]` (150 💎)**：發射自動追蹤導彈，命中產生大範圍高爆群傷，剋制密集怪群。

### 5. 🛠️ 升級、出售與實戰技巧
- **升級**：點擊已建造的防禦塔，可花費晶體升級至 Lv.2 / Lv.3 大幅提升攻擊力與射程。
- **折價出售**：點擊防禦塔並點「出售」可折價 70% 回收晶體，隨時依戰況重塑迷宮。
- **提早迎戰獎勵**：在波次間隔按 `[空白鍵 Space]` 或點擊「呼叫下一波」，提早迎戰可額外獲得 **+25 晶體獎勵**！
- **取消選取**：按 `[ESC]` 可退出造塔模式或取消選取防禦塔。

## 🚀 本地執行方式
本專案為純靜態網站，無需安裝 npm 或任何構建步驟：
1. 直接使用瀏覽器開啟專案根目錄的 `index.html`。
2. 或在專案目錄下啟動任意本地靜態伺服器（例如 `python -m http.server 8000` 或 VS Code Live Server）。

## 📦 目錄架構
```text
Game/
├── index.html                  # 遊戲大廳首頁（含分類、搜尋與遊玩指南）
├── css/
│   └── portal.css              # 大廳科技風樣式
├── js/
│   ├── games-data.js           # 遊戲清單數據庫
│   └── portal.js               # 搜尋、分類與動態渲染
└── games/
    └── cyber-defense/          # 首款塔防遊戲
        ├── index.html          # 遊戲入口（含戰情 HUD 與作戰說明彈窗）
        ├── css/
        │   └── game.css        # 戰情 HUD 與 Canvas 樣式
        └── js/
            ├── audio.js        # Web Audio API 合成音效引擎
            ├── pathfinding.js  # A* 尋路與防堵死驗證
            ├── entities.js     # 指揮官、塔、敵人、子彈、粒子
            └── game.js         # Canvas 主循環與戰鬥控制器
```
